# Focus Flow panorama

focus-landscape.png is an original decorative asset generated with the built-in image_gen tool on 26 October 2026 for the user-selected Focus Flow concept. Bundled locally; no runtime download, external image host or account data.

Prompt: An original panoramic quiet science fiction canyon, distant futuristic towers and a restrained circular structure, desaturated slate/navy atmosphere, pale amber sunrise, no text, logo, UI, characters or known franchise. Wide 3:1 composition suitable for responsive cropping into a low-height banner.

The app fits/crops the image to its panel with Pillow and hides it at short window heights. It is decorative and does not represent actual Quest artwork.
